Excuse-to-Email API

Turn "overslept, cat spilled coffee on my laptop, missed standup" into an email you can actually send. Rewrite the angry message before you hit send. Powered by Groq.

Get an API key

Free. One key per email, 50 requests per day. Your key is shown once, so copy it.

Quick start

curl -X POST /excuse \
  -H "X-Api-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"excuse": "up til 3am fixing prod, slept through the 9am client call", "sender": "Cam", "tone": "apologetic"}'
{
  "ok": true,
  "subject": "Apologies for missing this morning's call",
  "body": "Hi ...",
  "tip": "Send this before lunch and offer a specific time to reschedule.",
  "remaining_today": 49
}

Authentication

Send your key in the X-Api-Key header (or ?api_key= query param). Every response includes ok: true|false; errors include an error string.

POST /excuse

FieldRequiredDescription
excuseyesThe messy truth, up to 1000 chars
recipientnoWho it's for. Default "my manager"
sendernoYour name for the sign-off
contextnoAnything else to mention (e.g. "I'll make up the hours Friday")
tonenoprofessional (default), calm, friendly, firm, apologetic, concise, warm, neutral
honestynohonest (default) or vague — keeps it truthful but generic ("a personal matter")

Returns subject, body, tip, tone, remaining_today.

POST /tone

FieldRequiredDescription
textyesThe message you're about to regret, up to 3000 chars
tonenoSame options as above. Default calm
audiencenoe.g. "my landlord", "team channel"

Returns rewritten, changes[], anger_before (0–10), anger_after (0–10), remaining_today.

Errors

StatusMeaning
